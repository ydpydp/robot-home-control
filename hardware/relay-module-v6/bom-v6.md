# 继电器模块板 v5 — BOM（物料清单）

单继电器版本。板尺寸 **46.23 × 53.59 mm（竖版）**，布局按用户 2026-11-16
在嘉立创EDA 里重排的位置（.epro2 工程解析重建）。插 ESP32-C3 Super Mini
（2×8 排针座，横排，J1 在上、J2 在下）。12V DC 输入；继电器线圈直接挂 12V，
7805 只供 Super Mini 与 WS2812；ULN2003（SOIC-16）驱动一只 Songle
SRD-12VDC 继电器（K1，GPIO10 → U2 IN1/OUT1）。继电器 2（K2/J6/MH4）已按
用户要求去掉，下一版再说。端子：J5（WS2812）、J7（+12V 输出）与 J4
（继电器输出）在顶边、出线朝上；J3（12V 输入）、J8（+5V 输出）在底边、
出线朝下。

> 本表不含价格。参数以器件 datasheet 为准；括号内“以实测/卖家规格为准”表示该值
> 未逐一核对，采购前请按链接的型号核对一次。

## 逐件详细说明

### J1、J2 — Super Mini 插座（2× 1x08 排针）
- **规格**：单排 8 针，针距 2.54mm，直插（通孔），每排长约 20.3mm。
- **用法**：两排并排、中心距 15.24mm，拼成 2×8 插座，Super Mini 直接插上。
  引脚按板背丝印：J1 = 5V / GND / 3V3 / GPIO4 / GPIO3 / GPIO2 / GPIO1 / GPIO0；
  J2 = GPIO5 / GPIO6 / GPIO7 / GPIO8 / GPIO9 / GPIO10 / GPIO20 / GPIO21。
- **v5 布局**：两排横放，J1 在上、J2 在下，板子左侧。
- **采购**：买 2.54mm 单排母座（排母）8P×2 条，Super Mini 的公针插进去；
  若用公排针也可以，但板子就变成“被插”的那一方。孔位相同，公母通用。

### U2 — ULN2003A（7 路达林顿驱动）
- **电气**：7 路达林顿管，每路连续集电极电流 500mA，耐压 50V（Vce max）；
  输入兼容 5V TTL/CMOS，也接受 3.3V 逻辑。饱和压降约 0.9–1.1V（100–200mA 时）。
- **关键点**：
  - **反相**：输入高 → 输出低（对地导通）→ 继电器吸合。GPIO 高电平 = 继电器 ON，
    与之前 C3 直驱“低电平开通”相反，固件极性要翻过来。
  - **COM 脚（pin 9）必须接 +12V**：内部 7 只续流二极管共阳极到 COM 脚，
    继电器线圈断电时的反向电动势靠它泄放；COM 悬空会损坏芯片。
    （v3.4 起继电器改 12V，COM 由 +5V 改接 +12V。）
  - **v5 只用通道 1**：IN1/OUT1（pin 1 / pin 16）→ 继电器 1（K1，GPIO10）。
    通道 7（IN7/OUT7，pin 7 / pin 10）已随继电器 2 去掉，悬空不用；
    J2.2（GPIO6）原理图上标 no-connect。其余 5 路悬空不用。
    单路导通时电流约 30mA，芯片功耗可忽略，无需散热。
- **封装**：SOIC-16（SOP-16），本体 3.9 × 9.9mm，引脚间距 1.27mm；
  pin 1 在左上角，pin 8 = GND，pin 9 = COM，pin 16 = OUT1。
- **采购**：ULN2003AD（TI）或 ULN2003A（ST），SOIC-16 封装；
  注意别买成 ULN2003AN（DIP-16 直插版）。

### K1 — Songle SRD-12VDC-SL-C 继电器
- **线圈**：12V DC，电阻 400Ω ±10%，电流约 30mA，功耗约 360mW；
  吸合电压 ≤ 额定 75%（≤9V），释放电压 ≥ 额定 10%（≥1.2V）。
  （v3.4 起由 5V 改 12V：线圈直接挂 12V 轨，5V 不再负担继电器电流，
  以后加继电器也不怕 7805 过载；封装/脚位与 5V 版完全相同。）
- **触点**：单刀双掷（SPDT / Form C），COM / NO / NC 三端；
  额定 10A 250VAC、10A 125VAC、10A 30VDC（阻性负载）。
- **封装尺寸**：本体约 19 × 15.5 × 15.5mm（以 datasheet 为准），5 脚直插，
  脚距见 `Relay_SPDT_SANYOU_SRD_Series_Form_C` 封装。
- **⚠️ NO/NC 脚位务必实测**：SRD 的 NO/NC 取决于 datasheet 的观察方向，
  不同资料画法有歧义。**上电前用万用表通断档核对**：线圈不通电时 COM–NC 导通，
  线圈通电时 COM–NO 导通。确认无误后再接市电负载。
- **采购**：SRD-12VDC-SL-C（Songle 松乐），12V 线圈。v5 只有一只（K2 已去掉）。

### U3 — 7805 稳压器
- **电气**：5V 固定输出，额定电流 1A（L7805CV 标 1.5A，余量更大）；
  压差（dropout）约 2V，输入至少 ~7V 才能稳出 5V；本板输入 12V，正常工作。
  输出精度 ±4%（4.8–5.2V），内置过热/过流保护。
- **功耗**：12V 输入、约 150mA 负载时功耗 = (12 − 5) × 0.15 ≈ 1.05W。
  TO-220 裸片热阻约 50–65°C/W，温升约 50–70°C，结温在限值内，
  **本负载下不需要散热片**，保持周围通风、板上有铜皮辅助即可。
  若输入电压更高或负载更大，再考虑加散热片。
  （v3.4 起继电器线圈改挂 12V，5V 负载只剩 Super Mini 与 WS2812，
  实际 5V 电流比 150mA 更小，7805 更凉。）
- **引脚**：TO-220，1 = IN（12V），2 = GND，3 = OUT（5V），与 78M05 引脚相同，
  可以直接替换（78M05 是 500mA 版，7805 是 1A 版，余量更大）。
- **采购**：L7805CV（ST）或 LM7805CT（TI），TO-220 封装。

### C1、C3 — 100uF / 25V 贴片铝电解
- **规格**：铝电解，100uF，耐压 25V，贴片封装；实物底座 6.5×6.5mm、高 5.5mm。
  库里没有 6.5×5.5 这个型号，最接近的是 `CP_Elec_6.3x5.3`（与 6.3x5.4 焊盘
  完全一样，都是 ±2.8mm、3.5×1.6mm），6.5mm 的罐子直接焊在 6.3 的封装上没问题，
  只超出焊盘边缘各 0.1mm；焊盘中心距 5.6mm（±2.8mm）。
- **分工**：C1 = 12V 输入侧滤波，C3 = 5V 输出侧滤波。
- **⚠️ 有极性**：注意 + 极标记方向，焊反会损坏电容（甚至爆裂）。
  封装上 pin 1 为 + 极，对应板上丝印 + 号。
- **采购**：按规格买即可（100uF / 25V / 贴片铝电解，实物 6.5×6.5mm 底座、高 5.5mm），
  如 Panasonic EEE-FK 系列或同等品；耐压不低于 25V，温度 105°C 的更耐用。

### C2、C4 — 100nF / 50V 陶瓷电容（0805）
- **规格**：多层陶瓷（MLCC），X7R 介质，100nF（0.1uF），耐压 50V；
  0805 封装（2012 公制：2.0 × 1.25mm）。
- **分工**：C2 = 12V 输入侧高频旁路，C4 = 5V 输出侧高频旁路，紧贴 7805。
- **无极性**，随便焊。买 X7R 或更好的介质，别买 Y5V（容量随温度/电压漂移大）。
- **采购**：按规格买即可（100nF / 50V / X7R / 0805）。

### J3 — 12V 输入端子（2 针）
- **规格**：弯针拔插式端子，2 针，间距 3.5mm，直插；0.8mm 方针，板上孔径 Ø1.4mm
  （按用户给的图纸）。封装是项目自带、基于 Phoenix PT-1,5-2-3.5-H 改的
  （库里的 3.5mm 端子孔都是 Ø1.2，插 0.8 方针偏紧，按图纸放大到 Ø1.4）。
- **接线**：+ / − 按板上丝印接，别接反（接反会烧 7805 和电解电容）。
- **v5 位置**：底边，出线朝下。

### J4 — 继电器输出端子（3 针）
- **规格**：弯针拔插式端子，3 针，间距 3.5mm，直插；0.8mm 方针，板上孔径 Ø1.4mm。
  封装同上，基于 Phoenix PT-1,5-3-3.5-H 改。
- **接线**：COM / NO / NC 各一针。常用接法是火线进 COM、灯线接 NO（继电器吸合 = 灯亮）。
- **⚠️ 同样先万用表核对 NO/NC 再接市电**（见 K1 一节）。
- **v5 位置**：顶边右端，出线朝上。

### J5 — WS2812 接口（3.5mm 端子，2 针）
- **规格**：弯针拔插式端子，2 针，间距 3.5mm，直插；0.8mm 方针，板上孔径 Ø1.4mm。
  封装同 J3，基于 Phoenix PT-1,5-2-3.5-H 改。引脚是 DIN / GND。
- **接线**：板子只给数据 + 共地，不供 5V。灯带 5V 另从 J8（+5V 输出）取电，
  灯带 GND 与本板 GND 共地（插座的 GND 脚即是）。
  一颗 WS2812 全亮白光约 60mA，灯带长了 5V 电流从 J8 走、经 7805，
  注意 7805 总负载。
- **v5 位置**：顶边左端，出线朝上。

### J7、J8 — 低压电源输出端子（3.5mm 端子，2 针）
- **规格**：弯针拔插式端子，2 针，间距 3.5mm，直插；0.8mm 方针，板上孔径 Ø1.4mm。
  封装同 J3。
- **接线**：J7 = +12V / GND（直接取 12V 输入轨），J8 = +5V / GND（取 7805 输出）。
  供灯带、传感器等低压负载用；注意总电流别超过电源适配器与 7805 的余量。
- **v5 位置**：J7 在顶边（J5 旁边，出线朝上），J8 在底边（J3 旁边，出线朝下）。

### MH1–MH4 — M3 安装孔
- **规格**：孔径 3.2mm，带焊盘（可接地或不接），3 个。
- **位置**：MH1 左上、MH4 右上、MH2 右下、MH3 左下——四角各一（v6 恢复 MH4，顶边 J5/J7/J4 左移让位，端子间隙约 0.4mm）。
- **安装**：M3 螺丝 + 铜柱/尼龙柱固定；孔周围按封装 courtyard 留空，别布线。

## 电源说明

- **输入**：12V DC（J3），建议 12V / 1A 以上电源适配器。
- **分配**：继电器线圈直接挂 12V（约 30mA）；7805 只供 5V，
  负载是 Super Mini 与 WS2812（J8 输出），不再负担继电器。
- **负载估算**：12V 轨：继电器 ~30mA，加上经 7805 的 5V
  负载（Super Mini 约 100–200mA + WS2812），12V 总输入约 200–300mA，
  远低于 1A 适配器。5V 轨：约 150–250mA，远低于 7805 的 1A 额定。
  （若 Super Mini 的 WiFi 大流量工作，5V 电流会再高一些，但仍在 1A 内。）
- **功耗**：7805 上压降 7V × 约 0.2A ≈ 1.4W，裸 TO-220 可承受，见 U3 一节。
- **滤波**：C1/C3（100uF 电解）滤低频纹波，C2/C4（100nF 陶瓷）滤高频噪声，
  两级搭配，缺一不可。
- **输出**：J7 直接出 +12V，J8 出 +5V，供外部低压负载。

## 版本

- v5（2026-11-16）：单继电器版，布局按用户在嘉立创EDA 的重排（.epro2 解析重建）。
  相对 v3.6 的改动：去掉 K2、J6（继电器 2 下一版再说），MH4 在 v6 恢复；板子由 95×70mm
  横版改为 **46.23×53.59mm 竖版**；J5/J7/J4 移到顶边（出线朝上），J3/J8 在底边
  （出线朝下）；J1/J2 横排在左侧；U2 只用通道 1（GPIO10 → K1），通道 7 悬空。
  电气与 v3.6 相同（12V 继电器、7805 只供 5V、ULN2003 反相）。
- v3.6（2026-11-16）：去掉 J9（WS2812 只留一个输出）；J7（+12V 输出）、
  J8（+5V 输出）从底排移到左侧边，与 J5 并排；原理图重排进 A4。
- v3.4（2026-11-16）：继电器由 5V 改 12V（SRD-12VDC-SL-C，线圈 400Ω/约 30mA），
  线圈与 ULN2003 COM（pin 9）改挂 +12V，7805 只供 Super Mini 与 WS2812。
